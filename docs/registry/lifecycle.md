# Documentation Lifecycle

Registry entries use lifecycle states to make expectations explicit.

## Active

The documentation is current, maintained, and recommended for public use.

## Preview

The documentation is available for early access, beta programs, or upcoming public features. Preview entries should name the intended audience clearly.

## Deprecated

The documentation is still accessible, but users should migrate to a newer surface. Include migration guidance wherever possible.

## Archived

The documentation is retained for historical reference. Archived entries should not be presented as a current integration path.
