# Contributing

When adding or updating public documentation:

1. Confirm the content is intended for public readers.
2. Add or update the registry entry in `src/data/registry.ts`.
3. Keep the owner, status, and update date accurate.
4. Run a production build before deploying.

Use short, descriptive titles and avoid internal project names unless they are part of the public product surface.
