# Shogun Public Documentation

This site is the public registry for Shogun.dev documentation. It gives customers, partners, and contributors one place to find canonical documentation for active public services.

Learn how [Shogun Accounts](./shogun-accounts.md) work across Shogun Dot Dev apps and tools.

## What Belongs Here

- Product and service documentation intended for public readers.
- Public API references, SDK guides, integration notes, and release information.
- Operational documentation that helps users understand availability, lifecycle, or support expectations.

## Registry Principles

- Every entry has a clear owner and lifecycle state.
- Public links should resolve without private access.
- Deprecated documentation remains discoverable long enough for users to migrate.
