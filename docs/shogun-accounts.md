# One account for your Shogun tools

Your **Shogun Account** is the account you use with Shogun Dot Dev apps and tools, including Quiet, Bucketly, Tapdeck and Scribepane. If you already have an account, use the same sign-in method in another tool instead of creating a separate account. Available sign-in methods vary by app; Google manages its own password screens.

Sharing an account does not share every product's data or purchases. Each tool controls its own features, subscriptions and permissions. Staff access requires separate authorization. Sign-in on one device does not automatically sign you in everywhere.

## Email registration and passwords

Email registration requires verification. An accepted request is followed by instructions to check your inbox; it is not proof that you are signed in. If you already have a Shogun Account, sign in or request a password reset. Check spam folders if a verification email does not arrive.

Password fields in the updated account screens have a Show/Hide control. Passwords start hidden and are hidden again when you leave the screen or put the app in the background. Changing your Shogun Account password changes the password used across Shogun Dot Dev apps and tools.

## Quiet and phone numbers

Quiet does not ask for your phone number when creating a Shogun Account and does not read your SIM phone number. Caller numbers, allowlists, blocks and call activity are stored locally for call protection. Signing in does not upload them. Optional encrypted backups can include allowlist and blocked numbers, but exclude contacts and call history. Other products describe their own data handling; this is not a promise that every Shogun service never processes phone numbers.

## Account deletion

Deleting the shared account affects access to every Shogun Dot Dev app and tool using it. Read the scope and data-retention explanation before requesting deletion. Quiet's flow emails a confirmation code and requires a final confirmation. Product-local files and settings are not automatically erased by deleting an account.
